## 📖 Sobre o projeto

Neste repositório serão apresentados os principais comandos git, visando centralizar todos os comandos com uma breve descrição do que cada um deles realiza.
Este reepositório foi criado com o intuito de agilizar as pesquisas de comandos quando necessário, evitando a parada para pesquisas em sitios da internet.

## ⚙️ Como rodar o projeto

### Pré-requisitos

Antes de começar, você vai precisar de:

- [Git](https://git-scm.com/) instalado
- Um navegador moderno (Chrome, Firefox, Edge...)
- Um editor de código, como o [VS Code](https://code.visualstudio.com/)

### Passo a passo

```bash
# 1. Clone o repositório
git clone https://github.com/seu-usuario/nome-do-projeto.git

# 2. Entre na pasta do projeto
cd nome-do-projeto

# 3. Abra o index.html no navegador
# (ou use a extensão Live Server do VS Code)
```

Pronto! Se deu tudo certo, o projeto já está rodando na sua máquina. 🎉

## 🤝 Contribuindo

Contribuições são super bem-vindas! Quer ajudar? É só seguir:

1. Faça um **fork** do projeto
2. Crie uma branch para sua feature: `git switch -c minha-feature`
3. Faça suas alterações e o commit: `git commit -m "Adiciona minha feature"`
4. Envie para o seu fork: `git push origin minha-feature`
5. Abra um **Pull Request** 🚀

Encontrou um bug ou tem uma ideia? Abra uma [issue](https://github.com/pratesddev/git_principais_comandos/issues), sem cerimônia.
