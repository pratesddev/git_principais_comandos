## 📋 Sobre o projeto

Este respositório foi criado com o intuito de prover um compilado dos principais comandos Git, visando otimizar o tempo em pesquisas na internet em um momento de necessidade. A intenção é auxiliar o desenvolvedor com um repositório simples e de fácil entendimento.

### Objetivo

Auxiliar desenvolvedores nos comandos do Git de forma simples e objetiva.

### Escopo

Comandos desde a criação de um repositório GIT até Fluxo de trabalho típico

### Funcionalidades

- [ ] Apresentação dos comandos e da explicação de cada um deles
